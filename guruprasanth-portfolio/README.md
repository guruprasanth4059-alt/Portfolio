# Guruprasanth — Personal Portfolio

A responsive, dark-first portfolio website built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or use VS Code with the Live Server extension.

## Before publishing — personalize these items
1. In `index.html`, replace the sample `YOUR_EMAIL@example.com` email and the sample GitHub/LinkedIn links with your real profiles.
2. Add verified hackathon participation, awards, certifications, education, and dates if you want them shown. No achievements are invented in this template.
3. Add real repository/demo links to each project card when available. The current project links route to the contact section intentionally rather than pointing to unverified repositories.
4. Review project descriptions and stack labels so they reflect the current state of each project.
5. For deployment, upload the folder to GitHub Pages, Netlify, or Vercel static hosting.

## Features
- Responsive desktop, tablet, and mobile layout
- Dark/light theme toggle with saved preference
- Mobile navigation menu
- Project filtering by category
- Copy-email interaction with feedback
- Keyboard skip link, focusable controls, semantic sections, and reduced-motion support
- CSS-generated artwork; no external image assets are required for the live site

`assets/portfolio-concept.png` is a visual concept reference, not used as the page background.
